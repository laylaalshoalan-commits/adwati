# أدواتي
موقع أدوات عربية مجاني جاهز لـ GitHub Pages.

## النشر
1. أنشئ مستودعًا عامًا باسم `adawati`.
2. ارفع الملفات كلها.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. انتظر ظهور الرابط.
5. استبدل البريد في `contact.html` وأضف نطاقك لاحقًا إن رغبت.

## ملاحظة
قبل AdSense يجب إضافة محتوى أصلي مفيد، سياسة خصوصية حقيقية، شروط استخدام، وتفاصيل تواصل، ومراجعة متطلبات Google الحالية.
